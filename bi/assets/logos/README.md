# Tool logos

Locally bundled SVGs from [Simple Icons](https://github.com/simple-icons/simple-icons),
release [14.15.0](https://github.com/simple-icons/simple-icons/tree/14.15.0/icons),
downloaded on 2026-10-13: git, github, python, pytest, sqlite and streamlit.
The project is distributed under [CC0-1.0](https://github.com/simple-icons/simple-icons/blob/14.15.0/LICENSE.md).
Brand marks identify the tools used; no endorsement is implied.

Rendering uses only their path geometry, tinted with the established project
palette. No remote image or CDN is required at runtime.
