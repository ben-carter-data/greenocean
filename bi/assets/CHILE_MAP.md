# Chile regional map

Source: geoBoundaries gbOpen CHL ADM1, boundary year 2020, 16 regions.
Original providers: Biblioteca del Congreso Nacional de Chile (BCN), OCHA ROLAC.
License: CC BY 3.0 IGO. https://www.geoboundaries.org/api/current/gbOpen/CHL/ADM1/

The geometry is simplified for display, rounded to four decimals, and limited to
continental Chile and nearby islands. This is an analytical visualization, not a
legal boundary reference. The source metadata is preserved alongside the asset.
Names have been decoded and Biobío aligned to the project's dimension; no price
or index values are stored in the geometry. Values are joined at runtime from the
existing weekly snapshot; missing regions remain explicitly without data.
